# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for a security vulnerability.

Instead, email **info@videopro.io** with:

- A description of the issue and its potential impact.
- Steps to reproduce (a minimal repro is ideal).
- Any relevant logs or screenshots.

We'll acknowledge your report as soon as possible and keep you updated as it's investigated and fixed. Please give us a reasonable amount of time to address the issue before any public disclosure.

## Scope

This covers the console application in `console/` and this repository's `docker-compose.yml`/deployment configuration. For a vulnerability in OvenMediaEngine itself, please report it to the [OvenMediaEngine project](https://github.com/AirenSoft/OvenMediaEngine) directly.

## Supported versions

This project doesn't yet follow a formal versioning/release scheme — please report issues against the latest commit on `main`.
